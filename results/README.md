# Reference Results

This folder contains the key evaluation results from the thesis experiments.
These are tracked in the repository for reproducibility and reference.

All results can be regenerated from scratch by following the pipeline
instructions in the main [README](../README.md).

## Files
 
### Baseline (Balakirev HTR raw, no correction)
 
| File | Description |
|------|-------------|
| `baseline_cer.json` | Global metrics: CER 17.54%, WER 36.73%, 659 pages evaluated, model name, timestamp |
| `baseline_summary.csv` | CER and WER per year (17 years), with page count and total characters per year |
 
Regenerate: `bash scripts/docker/run_baseline.sh`
 
### Fine-tuning
 
| File | Description |
|------|-------------|
| `training_config.json` | Exact configuration used for the fine-tuning run: model (Qwen3-8B), LoRA params (rank 16, alpha 32), training params (3 epochs, lr 2e-4), paths, timestamp |
 
Regenerate: `bash scripts/docker/run_finetune.sh` (saved automatically after training)
 
### Evaluation — Test set (RV_1908, RV_1915)
 
| File | Description |
|------|-------------|
| `finetuned_test_summary.json` | Aggregated results: CER 10.86% → 7.80% (28.2% improvement), 16 improved, 2 fallback, 0 worsened, total time |
| `finetuned_test_detail.json` | Per-page results for all 18 test pages: CER before/after, WER before/after, inference time, fallback status and reason |
 
Regenerate: `bash scripts/docker/run_evaluate.sh test`
 
### Evaluation — Corpus-wide (other years)
 
| File | Description |
|------|-------------|
| `finetuned_easy_summary.json` | Easy pages (baseline CER < 12%) from train years: CER 10.37% → 9.66%, 4/10 improved |
| `finetuned_moderate_summary.json` | Moderate pages (baseline CER 14-19%) from train years: CER 17.06% → 16.81%, 2/10 improved |
 
Regenerate: `bash scripts/docker/run_evaluate.sh` with custom JSONL splits

## Key Results

## Data not in this repository
 
The following data is generated by the pipeline but not tracked in
the repository due to size. It can be regenerated with the scripts
or obtained from the indicated sources:
 
| Data | Size | How to obtain |
|------|------|---------------|
| **LoRA model adapters** | ~200 MB | Run `bash scripts/docker/run_finetune.sh` (56 min), or download from HuggingFace (see below) |
| **HTR raw output** (ALTO XML) | ~50 MB | Run `bash scripts/docker/run_balakirev_all.sh` (~1.5 hours) |
| **Fine-tuning dataset** (JSONL) | ~5 MB | Run `bash scripts/docker/run_prepare_finetuning.sh` |
| **Production output** (corrected JSON) | ~100 MB | Run `bash scripts/docker/run_production.sh` (~11-23 hours) |
| **Ground truth** (ALTO XML) | ~40 MB | Clone [RV-training](https://github.com/esthersole/RV-training) (private, request access from GReia) |
| **Page images** (PNG/JPG) | ~2 GB | Included in the RV-training repository |
